# Lumina 🌟
**Environmental Route Visibility Planner** — MVP for pedestrians, cyclists, and runners.

Lumina calculates environmental visibility factors (active storefronts, transit density,
lighting conditions, crowd levels, historical risk data) to offer 3 route options between
any two points on the city map.

> **Disclaimer**: This is an informational tool, not a substitute for personal vigilance.
> Urban conditions change rapidly. Always exercise personal judgement.

## Setup

### 1. Clone & create virtualenv

```bash
git clone <repo>
cd lumina
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure `.env`

```bash
cp .env.example .env
# Edit .env — OPENAI_API_KEY is optional; the app runs fully without it.
```

Key settings in `.env`:

| Variable | Default | Description |
|---|---|---|
| `OPENAI_API_KEY` | *(empty)* | Optional — enables LLM alert classification |
| `OPENAI_MODEL` | `gpt-4o-mini` | Model for alert classification |
| `CENTER_LAT` / `CENTER_LON` | `12.9757 / 77.6011` | Map center (Bengaluru MG Road) |
| `DEFAULT_START_LAT/LON` | `12.9820 / 77.5933` | Demo start point |
| `DEFAULT_END_LAT/LON` | `12.9687 / 77.6104` | Demo end point |
| `ALPHA_VIS` | `50` | Visibility cost weight |
| `ALPHA_PRACTICAL` | `15` | Practical cost weight |
| `ESCORT_THRESHOLD` | `30` | Score below which Escort Mode activates |

### 4. Run the app

```bash
streamlit run app.py
```

The first launch downloads the OSMnx graph (~30 s on a fast connection) and generates
`data/mock.json`. Subsequent launches use the cached GraphML file.

## 60-Second Demo Script

> Assumes the app is running at `http://localhost:8501`

1. **Accept ToS** — tick the checkbox and click *Continue to Lumina*.
2. **Default inputs are pre-filled** — Bengaluru MG Road area, Pedestrian mode.
3. **Click *Calculate Routes*** — three routes appear on the map:
   - 🔴 **Fastest Route** (red) — shortest path through the demo dark corridor
   - 🟡 **Practical Route** (amber) — moderate detour
   - 🔵 **Visibility-Optimized Route** (blue, glowing) — uses the lively street
4. **Toggle *Show segment-score overlay*** in the sidebar — edges color from red (low score) to green (high score). Notice the dark corridor on the fastest path.
5. **Select the Fastest Route** → click *Start Navigation*.
   - An **Escort Mode banner** appears immediately (dark corridor score < 30).
   - Poll rate changes to **3 s**. Contact notification is logged (simulated).
6. **After 30 s** — the **Eyes Up** overlay dims the screen with a large 👁 icon.
   - Click *Swipe to unlock map* to dismiss for 10 s.
7. **Try hour-of-day override = 14** (afternoon) in the sidebar, recalculate —
   broken-light penalties drop (×0.3 daytime), scores improve, Escort Mode may not trigger.

## Architecture Notes

- **Core modules** (`graph.py`, `scoring.py`, `routing.py`, `escort.py`) are pure-function
  modules returning `dict` / `GeoJSON`. They have zero Streamlit imports.
- **Scoring** uses vectorised `geopandas.sjoin` with `predicate="dwithin"` for fast
  spatial matching. Re-scoring on hour change recomputes only the time-dependent modifiers.
- **DEMO GUARANTEE**: `mock_data.generate_mock()` automatically plants a dark corridor
  on the fastest path's middle third and a lively high-score street on an alternative path,
  ensuring the 3 routes are visually distinct and the fastest triggers Escort Mode.
- **Telemetry swap point**: `escort.TelemetrySink` → swap `LocalJsonlSink` for
  `S3Sink` / `FirebaseSink` without changing any other module.
